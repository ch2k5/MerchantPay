# Merchant Pay

**Run the project in 5 commands**

```bash
# 1. Build and start services
make up

# 2. Seed demo data (optional, deterministic)
make seed

# 3. Run backend tests
make test

# 4. Start the Flutter web app
make run-web

# 5. Open http://localhost:8080 in your browser
```

The backend API will be available at `http://localhost:8000/api/v1/` and the Flutter web app at `http://localhost:8080/`.

See the `docs/` folder for detailed architecture, data model, and demo instructions.
